How to Use This Editor

  • JSON Editor: Direct access to edit the entire JSON file. Load → Edit → Save.
  • Quick Add: Simple forms to add companies, projects, or skills without touching JSON.
  • After saving, refresh your resume page to see changes.
  • Always download a backup of your JSON before making major changes!
