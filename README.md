# Hemanth Naidu - Professional Resume

This repository contains my professional resume in HTML format, along with comprehensive internal documentation of my work experience.

## Files

- **index.html** - Interactive HTML resume with Tailwind CSS styling
- **INTERNAL_DOCUMENTATION.md** - Detailed documentation of all projects, skills, and experiences

## How to View

### Option 1: Open Locally
Simply double-click `index.html` to open it in your default browser.

### Option 2: Live Preview
You can host this on GitHub Pages or any web hosting service to create a live resume website.

### Option 3: Print to PDF
1. Open `index.html` in your browser
2. Press `Ctrl+P` (Windows/Linux) or `Cmd+P` (Mac)
3. Choose "Save as PDF" as the destination
4. Adjust settings for best results (remove headers/footers)

## Features

- **Fully Responsive** - Works on all devices (desktop, tablet, mobile)
- **Print-Friendly** - Optimized for printing to PDF
- **Modern Design** - Clean, professional gradient design with Tailwind CSS
- **Interactive** - Hover effects and smooth animations
- **Comprehensive** - Showcases 4+ years of professional experience

## Customization

To update the resume:
1. Edit `index.html` directly
2. All content is in plain HTML with Tailwind CSS classes
3. No build process required - just edit and refresh

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript (for interactivity)
